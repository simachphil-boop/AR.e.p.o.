# AR.E.P.O. 🏺

AR-игра в духе R.E.P.O. для телефонов Huawei (HUAWEI AR Engine): твоя квартира превращается в уровень.

- **Сканирование**: проходишь по всей квартире, игра запоминает пол, столы, диваны, двери и строит карту.
- **Ценности**: каждый уровень раскладываются заново в случайных местах. Если дёргать или ронять, бьются и дешевеют.
- **Квота и точка сдачи**: относишь вещи в светящийся круг и сдаёшь, когда набрал квоту.
- **Монстры**: 👤 Тень охотится, 🗿 Статуя двигается, только когда на неё не смотришь, 🕷 Прыгун делает рывки.
- **Магазин**: здоровье, сила захвата, длинные руки, броня, карта ценностей, детектор, радар, аптечки, шокер, магнит.

APK собирается через GitHub Actions, готовый файл лежит в **Releases**.
